# My Personal Site
This is a personal site about me. It shows who I am, what I do, etc.
The website is divided into sections that each have a different topic.
The first section is simply an "About Me". 
The second section talks about my previous projects; the third is about contacts.
Lastly, I write about what I want to do in the future.

I made the project by first writing the HTML for the main features, such as the different sections, using the 'div' tag. Some other elements I added were a hyperlink that led to a YouTube channel that I unfortunately stopped adding to a couple of years ago, and a navigation bar that jumps to the section you click on. After that, I wrote the CSS to add a blue theme to the web page. I made this project because I wanted to learn the basics of HTML and CSS, and deploy my first site for everyone to see.

After shipping the project, I might make the website look more aesthetic and appealing, and add more features, such as an image carousel.

I took lots of inspiration from W3Schools.
